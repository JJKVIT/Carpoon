# Carpoon

A project directory manager for your command line.

> *"dont ask me who need this"* - [me](https://github.com/JJKVIT)

Designed to help you navigate and manage your project directories from the terminal, Carpoon is built in Go and utilizes a TUI (bubbletea).

## 🚀 Features

* **Project Management**: Organize and access your project directories quickly.
* **Configuration**: Customizable via `carpoon.json`.

## 🛠️ Installation

### Prerequisites

* [Go](https://go.dev/dl/) 

### Build from Source

1.  Clone the repository:
    ```bash
    git clone [https://github.com/JJKVIT/Carpoon.git](https://github.com/JJKVIT/Carpoon.git)
    cd Carpoon
    ```

2.  Build the executable:
    ```bash
    go build -o carpoon .
    ```

3.  (Optional) Move the binary to your PATH to run it globally.

## 📖 Usage

Run the application from your terminal:

```bash
./carpoon
```
or if you have added it globally
```bash
carpoon
```

Other commands can be seen in the help menu in the carpoon tui
